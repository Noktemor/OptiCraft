# Порталы: исправление команд и переходов (18.11.2026)

## Сделано

- `/portal build nether` и `/portal build end` ставят портал **перед игроком** по направлению камеры. Рамка Nether ориентируется лицевой стороной к игроку.
- Если нужные чанки ещё не загружены, команда ставит строительство в очередь. Ответ в чате: `Portal queued (waiting for nearby chunks)`. После появления нужных чанков сообщение: `Portal built: nether` / `Portal built: end`.
- Перед изменениями проверяется готовность **всех** блоков конструкции. Частично построенный портал из-за отсутствия чанка не допускается.
- `/portal status` показывает текущее измерение и наличие ожидающего задания на строительство. В чате работают варианты автодополнения `/portal`.
- `/portal ignite` не сообщает об успешной активации, если блоки портала нельзя изменить из-за отсутствующего чанка.
- Командный End-портал строится активным с заполненной рамкой. Ручная активация существующей рамки глазами Эндера сохранена.
- При переключении измерений сбрасываются скорость и отслеживание урона от падения. Для Nether проверяется безопасная точка появления: сначала вблизи координат назначения, затем запасная стартовая пещера.

## Применение

1. Распаковать архив целиком в **новую папку**. Проверить наличие `OptiCraft/PORTAL_PATCH_ID.txt` — это маркер исправленной версии.
2. Открыть **эту** папку `OptiCraft` в CLion как CMake-проект и пересобрать приложение. Не запускать бинарник из старой папки сборки.
3. Запустить мир, нажать `T`, набрать `/portal status` и нажать Enter. Либо открыть чат клавишей `/` и дописать `portal status`.
4. Для постройки: `/portal build nether` или `/portal build end`. Не отходить далеко, если показано `Portal queued` — дождаться загрузки соседних чанков.
5. Для прямой проверки переходов: `/portal nether`, `/portal end`, `/portal overworld`.
6. Файл реестра дополнительных измерений: `OptiCraft/assets/dimensions.json`. Nether и End — встроенные; поэтому исходный файл содержит пустой список `dimensions`.

## Протестировано

- `tools/tests/portal_geometry_smoke.cpp`: отдельно скомпилированный C++ тест геометрии порталов, отрицательных координат и двух ориентаций Nether.
- `tools/tests/test_worldgen_fastpaths.py`: 130277 сценариев.
- Контракты косметического рендеринга, границ мешей и GPU-подготовки.
- Наличие и целостность JSON-ресурсов, исходников и итогового ZIP.
