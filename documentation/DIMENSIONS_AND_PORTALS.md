# OptiCraft — измерения, Nether, End, порталы

## Сделано

- Сохранена существующая архитектура `Chunk_Manager`, `Renderer`, `World_Generator` и раздельные ключи хранения чанков измерений. Overworld использует прежний ключ; данные старых миров не переименовываются.
- В `Dimension.cpp` добавлен динамический реестр: встроенные измерения `overworld`, `nether`, `end` и прежние тестовые режимы; дополнительные определения из `assets/dimensions.json`.
- Независимая генерация Nether: потолок и нижний слой, крупные пещеры, лавовый уровень, незерак, базальт, безопасная стартовая каверна и светящийся камень. Генерация зависит от координат и seed, границы чанков согласованы.
- Независимая генерация End: центральный остров, внешние острова, пустота, шесть экспериментальных обсидиановых монолитов.
- Реализованы пространственные портальные блоки, рамки, переход после нахождения в портале, задержка повторного срабатывания, создание обратной точки перехода после загрузки её чанков.
- Портальные перемещения Overworld/Nether пересчитывают X/Z в масштабе 8:1 при каждом переходе. Переходы в End ведут на центральный остров; выход возвращает на исходный спавн Overworld, а не к прежней позиции.
- Позиции игрока сохраняются отдельно для каждого измерения. Урожай и саженцы имеют отдельные файлы состояния, мобы и менеджер логики очищаются при переключении. Стриминг и очереди старого измерения сбрасываются с прежним Chunk_Manager.
- Встроенная проверка валидности имён измерений защищает пути сохранений от невалидных идентификаторов.
- Добавлены текстуры и блоки для обоих миров; специальный цвет фона и отсутствие солнца/луны.

## Игровое использование

### Nether

1. Построить **вертикальную** обсидиановую рамку с внешним размером **4 блока в ширину × 5 в высоту** и пустым внутренним проёмом 2×3. Допускаются плоскости X/Y и Z/Y.
2. Взять `Flint And Steel` (огниво, ID 525) и нажать ПКМ возле рамки для активации. При успешной активации образуются блоки `Nether Portal`. С версии 0.12.1 также можно использовать отдельную `Lighter` (ID 528), которая поджигает поверхности и активирует рамки.
3. Войти в светящийся проём и находиться в нём ~0,8 секунды.
4. Появление на другой стороне задерживается до готовности чанков; сначала выбирается существующий портал из реестра `portal_sites.txt`, затем ищутся старые порталы в загруженной области. Новый портал строится, только если подходящий не обнаружен.

### End

1. Построить **горизонтальную** рамку **5×5** из `End Portal Frame` (ID 522), оставив 3×3 воздуха внутри.
2. ПКМ предметом `Eye Of Ender` (ID 526) по каждому из 16 блоков рамки. Заполненные ячейки становятся `End Portal Frame Filled` (ID 527).
3. После заполнения последней ячейки 3×3 внутри активируется; прыгнуть в неё.
4. В End игрок появляется на центральном острове. Для возврата рядом создаётся работающий выходной портал.

### Команды отладки

- `/portal nether` — немедленная смена измерения; повторная команда восстанавливает прежнюю позицию в нём.
- `/portal end` — перейти в End.
- `/portal overworld` — перейти в основной мир.
- `/portal build nether` — мгновенно построить активную рамку рядом с игроком.
- `/portal build end` — построить активный портал в End без установки глаз.
- `/portal ignite` — найти и активировать готовую обсидиановую рамку поблизости.
- `/portal <имя>` — перейти в дополнительное зарегистрированное измерение.

## Дополнительные миры

`assets/dimensions.json` позволяет добавлять сколько угодно именованных измерений без расширения `enum`. Пример:

```json
{
  "dimensions": [
    {
      "name": "ashlands",
      "display_name": "Ashlands",
      "terrain": "nether",
      "coordinate_scale": 2.0,
      "has_sky_light": false,
      "decorations": false,
      "fixed_time": true,
      "spawn_height": 66
    },
    {
      "name": "workshop",
      "display_name": "Workshop",
      "terrain": "flat",
      "flat_base_y": 0,
      "layers": [
        {"block_id": 5, "thickness": 3},
        {"block_id": 2, "thickness": 2},
        {"block_id": 1, "thickness": 1}
      ]
    }
  ]
}
```

Поддерживаемые значения `terrain`: `noise`, `flat`, `void`, `nether`, `end`. Имена — только строчные латинские буквы, цифры, `_` и `-`, длина до 64. Уникальный ключ имени становится частью хранения данных измерения. После редактирования JSON перезапустить игру; при использовании ускоренного бинарного ассета обновить его с помощью `tools/json2bin`.

## Осталось

- **Не выполнен полный CMake build и запуск игры:** в окружении сборки нет системных пакетов OpenGL/GLFW/GLM. Проверить компиляцию и поведение в CLion.
- Нужна игровая проверка геометрии портальных блоков, освещения, коллизий, переходов на границе чанков и сохранения при рестарте.
- Нет отдельных мобов Nether/End, боёв с боссом, крепостей, крепостных структур, крафтов глаз/огнива и анимированных материалов порталов. Эти вещи не заявляются как реализованные.
- Старые форматы сохранения чанков сохраняются; **перед первым запуском с этим обновлением сделать резервную копию мира**.

## Дополнение 0.12.1: огонь, высота и выход из End

- Nether генерирует ландшафт в Y=0…512, крыша Mantle Stone на Y=512. Строительство на крыше возможно до Y=1024.
- Зажигалка Lighter создаётся из Iron Ingot + Charcoal. ПКМ по поддерживаемой поверхности создаёт Fire, которое постепенно гаснет, ограниченно распространяется и может сжечь древесину/листву/шерсть.
- Живой огонь хранится в `fires_nether.txt` и аналогичных файлах измерений.
- Выход из End не строит новый портал в Overworld, а переносит на первоначальный спавн.
- Для старых чанков Nether остаётся прежний ландшафт до их регенерации; существующие сохранения не удаляются автоматически.
