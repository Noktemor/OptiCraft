# OptiCraft — устранение зависаний измерений (19.11.2026)

## Сделано

- `Chunk_Manager`: отключено создание и исполнение задач **skylight** для измерений с `has_sky_light=false` (Nether/End). Освещение от блоков оставлено работающим.
- `World_Generator`: вычисление 2D-профиля острова Энда, столбов и шумов перенесено из каждого вокселя в один вызов на X/Z-колонку внутри чанка. `get_height()` также использует однократный расчёт профиля; геометрия не изменена.
- `Game::construct_portal_at`: создание 20/34 клеток портала выполняется одной пакетной операцией `set_blocks_world_batch` вместо множества независимых пересчётов света и сохранений.
- `Chunk_Manager::prepare_for_reload` и `Game::reload_world`: задания предыдущего измерения останавливаются и потоки завершаются **до** очистки чанков и освобождения слотов. Не изменяется структура крупных менеджеров.
- `Game::switch_dimension`: запись настроек и позиции в новом измерении больше не делает повторный синхронный `save_all()` сразу после создания пустого менеджера. Сохранение старого мира остаётся обязательным.
- Добавлены точки логирования `Dimension switch` / `World reload`, чтобы определить, на каком этапе остановился переход, если проблема сохраняется.

## Осталось

- Собрать и запустить проект в CLion с установленными GLFW / GLM / OpenGL; текущая среда сборки не содержит OpenGL development libraries.
- Проверить в Release переходы `/portal end`, `/portal overworld`, `/portal nether` и физический портал, особенно на старом сохранении с большой дальностью прорисовки.
- Сравнить `game.log` до/после. Если игра снова зависнет, последний лог `World reload:` покажет участок блокировки. Для диагностики настоящего deadlock нужен stack trace всех потоков **в момент зависания**, т.к. в ранее приложенной записи Tracy есть только Overworld без момента остановки.

## Проверка

1. Скопировать папку сохранения мира перед запуском.
2. Распаковать **весь** архив в новую папку, открыть именно её в CLion и собрать в Release.
3. Проверить, что `PORTAL_PATCH_ID.txt` содержит дату `2026-11-19`.
4. После загрузки мира ввести `/portal status`, `/portal end` и дождаться загрузки острова; затем `/portal overworld` и `/portal nether`.
5. Если в новом архиве опять будет полный зависон, сохранить `game.log` и выполнить в терминале: `gdb -p $(pidof OptiCraft) -batch -ex 'thread apply all bt 20' > hang_threads.txt` (если система разрешает attach).

Файл `assets/dimensions.json` включён. Для Nether и End соответствующие определения встроены в реестр, поэтому пользовательский список может оставаться пустым.
