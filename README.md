# OptiCraft

OptiCraft — учебный C++-проект воксельного игрового движка в духе Minecraft. Проект использует OpenGL, потоковую загрузку чанков, процедурную генерацию мира и GPU-driven рендеринг.

## Быстрый старт

Нужны CMake 3.16+, компилятор C++20, OpenGL и GLFW; на Linux также X11 и Threads. Зависимости и опции описаны в [технической документации](documentation/TECHNICAL_DOCUMENTATION.md).

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 4
cd build && ./OptiCraft
```

Ресурсы копируются в каталог сборки. Для переносимого исполняемого файла задайте `-DOPTICRAFT_NATIVE_ARCH=OFF`. Настройки игры сохраняются в `options.txt` относительно рабочего каталога. В текущей конфигурации CTest автоматические тесты не зарегистрированы.

Настройка сложности доступна внутри мира и влияет на лимит враждебных мобов ночью. Мирные и враждебные мобы появляются в обоих режимах; удалённые обычные мобы исчезают без добычи. Подробности — в [разделе о мобах](documentation/TECHNICAL_DOCUMENTATION.md#47-мобы).

Документация: [архитектура и сборка](documentation/TECHNICAL_DOCUMENTATION.md), [рендеринг](documentation/RENDERING_PIPELINE.md), [профилирование](documentation/PROFILING.md), [дорожная карта](documentation/ROADMAP.md), [история изменений](documentation/history_version.md). Исторические замеры и планы описывают состояние на момент их создания.

## Версия 0.11

В этом обновлении продолжена работа над графикой и потоковой загрузкой мира. Построение мешей чанков выполняется на GPU асинхронно: прежний меш остаётся видимым до готовности нового. При изменении блоков перестраиваются затронутые секции; также доработаны отсечение невидимой геометрии, LOD и отдельный проход отрисовки воды.

Генерация чанков стала гибридной: часть вычислений подземных материалов для дальних чанков может выполняться на видеокарте с помощью compute-шейдера. Подготовка данных и завершение генерации, включая пещеры, реки, поверхность и структуры, остаются на CPU. При недоступности или недостаточной скорости GPU используется CPU-путь. Подробнее — в [описании гибридной генерации](documentation/GPU_WORLDGEN_HYBRID.md).

По результатам игрового теста на Intel Core i5-13420H с 16 ГБ DDR5 при дальности прорисовки 48 чанков во время полёта наблюдалось около **80–100 FPS**. При этом перед игроком успевало появляться большое количество чанков: скорость генерации превышала **100 чанков в секунду**. Это результаты конкретного теста; производительность зависит от оборудования и условий игры.

По сравнению с прежними тестами производительность в 0.11 значительно выросла — разница ощущается как небо и земля. Этот результат связан с новой архитектурой потоковой загрузки, генерации и GPU-рендеринга чанков. Старые замеры в документации относятся к прежнему состоянию проекта и не отражают итоговую производительность 0.11; напрямую сравнивать цифры без одинаковых условий тестирования нельзя.

На данный момент циклы оптимизации графики приостановлены: дальнейшая работа над ней уже становится чрезмерной, и пришло время уделить внимание другим частям проекта.
