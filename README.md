# OptiCraft

OptiCraft — воксельный игровой движок на C++20 в духе Minecraft с процедурной генерацией мира, потоковой загрузкой чанков и GPU-driven рендерингом. Поддерживаются Vulkan и OpenGL.

## Версия 0.13.1 — Vulkan test 2

Вторая пробная версия Vulkan-рендерера (Stage 150). Vulkan автоматически выбирается при наличии подходящего устройства и сборки; при ошибке инициализации используется OpenGL.

- GPU-хранение исходных блоков, compute-мешинг, пакетные indirect draws, геометрический LOD, frustum culling и Hi-Z.
- Приоритетный ремешинг при разрушении и установке блоков.
- Гибридная GPU-генерация климата, рельефа, пещер, рек, деревьев и структур; экспериментальное GPU-владение дальними чанками, передача на CPU и фоновое сохранение.
- Межчанковое освещение, адаптивные бюджеты GPU-работы и учёт явных выделений видеопамяти.
- Нативные проходы мира, мобов, боссов, предметов и HUD. Восстановлены кубическая листва, полупрозрачность воды и сглаживание ближнего opaque-освещения.

**Статус:** экспериментальная сборка. GPU Worldgen пока частично зависит от CPU, скрытый OpenGL-контекст сохраняется, полноценные динамические тени и точный свет при отсутствующих верхних чанках ещё не завершены. Автономные тесты Stage 150 — 10/10; полноценная сборка и аппаратная валидация Vulkan ещё необходимы. Перед тестированием рекомендуется создать резервную копию мира.

**Полная техническая реализация:** [Vulkan_Render.md](Vulkan_Render.md) — актуальная архитектура, форматы данных, алгоритмы, проходы, ограничения и полный журнал Stage 2–150.

## Быстрый старт

Нужны CMake 3.16+, компилятор C++20, GLFW, OpenGL, Vulkan SDK/headers и `glslangValidator` для Vulkan-пути; на Linux также X11 и Threads.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 4
cd build && ./OptiCraft
```

В CLion запускается основная цель `OptiCraft`, без дополнительных переключателей. `OptiCraft_Vulkan` — отдельный тест presentation/swapchain, а не игра. При необходимости `OPTICRAFT_RENDERER=opengl` принудительно выбирает OpenGL; `OPTICRAFT_VULKAN_GPU=integrated` или `discrete` задаёт предпочтительное устройство. Для переносимой сборки — `-DOPTICRAFT_NATIVE_ARCH=OFF`. Настройки сохраняются в `options.txt` относительно рабочего каталога.

Альтернативная установка для Windows и Linux: [OptiCraft Installer](https://github.com/Noktemor/OptiCraft_Installer).
